### 升级说明

- 覆盖 exe 即可，`configs/`、`devices.json`、`user_settings.json` 会保留；
- 如果新版本改动了配置字段（`version` 提升），Release 说明会单独标注迁移方法；
- 回滚：换回旧 exe 即可，本程序不写注册表（仅开机自启会在启动项里留一条记录）。
