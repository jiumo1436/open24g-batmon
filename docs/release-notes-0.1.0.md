# v0.1.0 · 首个公开版本

配置驱动的 2.4G 无线外设电量监控工具，首个对外版本。程序本体不含任何设备协议，
所有帧头、偏移、换算、校验规则全部来自 `configs/` 下的 JSON 配置文件。

**发布日期**：2026-11-03
**适用系统**：Windows 10 / 11（64 位）
**配置文件版本**：`version: 1`

---

### 下载

| 文件 | 说明 |
| --- | --- |
| `open24g-batmon-0.1.0-win64.zip` | 免安装，解压即用（含 exe + configs + 快速开始） |
| `open24g-batmon-0.1.0-win64.zip.sha256` | 校验和 |

解压后目录结构：

```
open24g-batmon-0.1.0-win64/
├── 设备电量监控.exe
├── quick-start.txt
└── configs/
    ├── example-mouse.json
    ├── example-keyboard.json
    └── example-headphone.json
```

首次启动是空列表，点「＋ 导入设备 → 浏览 configs」导入需要的设备即可。

> 随包的 3 份 `example-*.json` 是**纯虚构语法样例**（VID 统一 `0x1234`），
> 不对应任何真实硬件，导入后读不到数据 —— 用途是给你照着写自己的设备。
> 真实可用的配置请在仓库 `configs/` 里找，或按教程自己抓包编写。

### 功能

**读取引擎（全部由配置驱动）**

- 传输层：USB HID（含报告 ID、输出报告握手）与串口接收器，两种通道统一抽象
- 定位：按字节偏移读取，支持任意字节序、位掩码、位移
- 换算：`scale` / `offset`、分段线性 `map` 插值、白名单 AST 表达式 `formula`
- 校验：无校验、求和（正/反码）、异或、CRC8/CRC16，支持帧头与帧长偏移
- 特殊字段：`zero_is_off`（关机仍回数据时识别为"未响应"而非 0%）、电压直读 `read_as=voltage`

**软件本体**

- 主界面卡片列表，显示设备名、电量、充电状态、最后更新时间
- 托盘图标环形电量：1~3 台设备分别为单环/双环/三环，0 台显示灰色空环
- 自动刷新（默认 20 秒）、手动刷新、批量并发读取（上限 8 线程）
- 开机自启、低电量弹窗提醒（阈值可调）、托盘图标颜色自定义（低/中/高档位）
- 配置导入对话框、串口端口选择、协议测试工具、抓包辅助窗口
- 偏好保存在同目录 `user_settings.json`，升级覆盖 exe 不会丢失

**健壮性**

- 配置文件 JSON/YAML 语法错误给出**中文行号定位**提示，不会崩溃
- 单台设备读取失败不影响其他设备；设备拔出后自动转为「未响应」
- 日志超过 1 MB 自动滚动，最多保留一份历史
- 单实例运行，重复启动会激活已有窗口
- 损坏的 `devices.json` 自动降级为空列表并备份

### 已知问题

- **串口接收器仅完成协议解析与端口打开验证，尚未在真实串口接收器上跑通端到端读数**，
  欢迎有硬件的朋友实测后反馈（附带抓包日志）。
- 部分机型在 USB 3.0 接口上偶发丢包，重试后恢复。
- 暂不支持蓝牙设备 —— 本项目只处理 2.4G 接收器。
- 仅 Windows 平台构建，未做 macOS / Linux 适配。

### 升级说明

- 覆盖 exe 即可，`configs/`、`devices.json`、`user_settings.json` 会保留；
- 回滚：换回旧 exe 即可。本程序不写注册表（仅开机自启会在启动项里留一条记录）。
