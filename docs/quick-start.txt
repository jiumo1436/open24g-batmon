open24g-batmon 0.1.0  ·  2.4G 外设电量监控
================================================

【怎么用】

1. 双击「设备电量监控.exe」，程序会在任务栏旁边（托盘区）显示环形电量图标；
   双击图标或点右键 →「打开主界面」可以看到完整列表。
2. 首次启动是空列表，因为本程序不含任何内置设备协议。
3. 点界面左上角「＋ 导入设备」→「浏览 configs」→ 勾选要监控的设备 → 导入。
4. 导入后程序开始读取电量。笔记本内置电池、USB 接收器都可能被识别到，
   按需取消勾选即可。

【configs 里面是什么】

configs\example-mouse.json     HID 单字节读取 + 反码校验 + 充电位        （虚构样例）
configs\example-keyboard.json  握手帧 + 两字节小端 + 尾部求和校验        （虚构样例）
configs\example-headphone.json 串口接收器 + 电压映射 + 关机识别          （虚构样例）

这三份是**纯虚构的语法样例**，VID 统一写成 0x1234，不对应任何真实硬件，
导入后不会读到数据 —— 它们的作用是让你照着格式写自己的设备。

【想支持你自己的设备】

去仓库拿模板和教程：
  https://github.com/jiumo1436/open24g-batmon
  configs\template.json          字段逐行中文注释
  docs\config-making-guide.md    抓包 → 定位帧 → 写配置 → 验证，全流程
  docs\config-schema.md          每个字段的准确含义

写好后放进 configs\ 目录，回到软件「＋ 导入设备」里勾选导入即可，不用改代码。
读取成功的话，欢迎把配置连同抓包日志和实测截图提 PR，让更多人用上。

【常见问题】

· 导入后一直显示「未响应」：检查 VID/PID 是否填对，接收器是否插在 USB 2.0 口上。
· 电量显示 0%：部分设备关机时仍会回数据，给配置加 "zero_is_off": true 即可。
· 开机自启、托盘图标颜色、低电量提醒：都在「设置」里。

【注意】

本程序不写注册表（仅开机自启会在启动项留一条记录），删除整个文件夹即可卸载。
个人偏好保存在同目录 user_settings.json，升级时覆盖 exe 不会丢。
